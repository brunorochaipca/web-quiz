Cast entre int e double

int para double · automático

int x = 5;
double y = x;
System.out.println(y); // 5.0

Não há perda, por isso o Java converte sozinho. A consola mostra 5.0, com a parte decimal.

double para int · é preciso (int)

double preco = 9.99;
// int n = preco;    não compila
int n = (int) preco; // 9

Perde a parte decimal, por isso o Java recusa. O cast corta, não arredonda: 9.99 fica 9, não 10.

O cast tem de ser antes da divisão

int a = 10, b = 3;
double c = a / b;          // 3.0
double d = (double) a / b; // 3.333…

a / b já é divisão de dois int e dá 3. Guardar esse 3 num double só o transforma em 3.0. (double)(a / b) também chega tarde.

2. Operações

+ - * / % · atalhos += -= *= /= %= · ++x soma antes de usar, x++ usa e só depois soma. O mesmo para --. Avalia-se da esquerda para a direita.

int a = 5;
int b = ++a + a--;
// ++a faz a=6 e vale 6
// a-- vale 6 e depois a fica 5
// b = 12. Consola: 5 12

5. switch / case

Serve para int, char e String. Não serve para double, boolean nem long. Sem case correspondente, corre o default. Se não houver default, não corre nada. break sai do switch.

Teu exercício · FichaPratica02 / Ex04 · lugar na corrida

switch (lugar) {
    case 1: pontos = 10; break;
    case 2: pontos = 8;  break;
    case 3: pontos = 6;  break;
    case 8: pontos = 1;  break;
    default:
        System.out.println("Não ganhou pontos");
}
if (pontos == 1)
    System.out.println("Ganhou " + pontos + " ponto.");
else if (pontos > 0)
    System.out.println("Ganhou " + pontos + " pontos.");

Teu exercício · FichaPratica02 / Ex12 · menu

switch (opcao) {
    case 1: System.out.println("Criar");      break;
    case 2: System.out.println("Actualizar"); break;
    case 3: System.out.println("Eliminar");   break;
    case 4: System.out.println("Sair");       break;
    default: System.out.println("Opção inválida!");
}

Sem o break do case 1, uma opção 1 imprimiria também o texto do case 2. Vários case seguidos, sem código no meio, partilham o bloco de baixo.

6. while

Testa a condição e, se for verdadeira, corre o corpo. Algures no corpo a condição tem de poder ficar falsa, senão o ciclo não acaba.

Teu exercício · FichaPratica03 / Ex01 · contar

int numero = 1;
while (numero <= 250) {
    System.out.println(numero);
    numero++;
}

Teu exercício · FichaPratica03 / Ex09 · ler até −1 e fazer a média

int num = 0, soma = 0, i = 0;
while (num != -1) {
    num = input.nextInt();
    if (num > -1) {
        i++;
        soma += num;
    }
}
if (soma != 0) {
    float media = (float) soma / i;
    System.out.println("Média é: " + media);
}

O (float) é obrigatório: soma e i são int, e sem o cast a divisão seria inteira. O −1 é lido, mas o if deixa-o fora da soma.

Molde · somar só os pares de 1 a 10

int n = 1, soma = 0;
while (n <= 10) {
    if (n % 2 == 0) soma += n;
    n++;
}
// soma = 2+4+6+8+10 = 30

7. do / while

Corre o corpo e só depois testa. Por isso executa pelo menos uma vez, mesmo que a condição já seja falsa. O ; depois do while faz parte da sintaxe.

Teu exercício · FichaPratica04 / Ex05 · menu que repete

int opcao;
do {
    opcao = input.nextInt();
    switch (opcao) {
        case 1: System.out.println("Criar"); break;
        case 2: System.out.println("Actualizar"); break;
        case 3: System.out.println("Eliminar"); break;
        case 4: System.out.println("Sair"); break;
        default: System.out.println("Opção inválida!");
    }
} while (opcao != 4);
int n = 5;
do {
    System.out.print(n);
    n--;
} while (n > 5);
// imprime 5 e pára: 4 > 5 é falso

8. for

Ordem: inicialização, condição, atualização. A atualização corre no fim de cada volta, antes de voltar a testar.

Teu exercício · FichaPratica_ExtraCiclos / Ex04 · for dentro de for

for (int x = 0; x < 4; x++) {
    for (int i = 0; i < 10; i++)
        System.out.print("*");
    System.out.println();
}
for (int x = 0; x < 5; x++) {
    for (int i = 0; i <= x; i++)
        System.out.print("*");
    System.out.println();
}

No segundo, cada linha tem mais um asterisco: 1, 2, 3, 4 e 5. O ciclo de dentro recomeça do zero em cada volta do de fora. A descida escreve-se for (int i = 5; i > 0; i--).
